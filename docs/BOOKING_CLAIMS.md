# 约场时段认领

组织者可以先统一登记自己为约场人，再由实际预约并垫付场费的球友认领相应时间。活动接龙页每片场地的「约场时段认领」中列出各段时间、当前登记人及是否已经认领；赛事活动也显示相同入口。开始和结束时间使用站内选择器，按马德里时间显示。

## 成员认领

- 启用账号的球友可直接认领自己实际预约的时间，无需组织者批准；不要求本人在这片场地报名，因为也可能替群里约场而不参加。
- 时间必须在该场地预约内，以半小时为步长，认领至少一小时，拆分后的约场段也至少一小时。整个预约本来不足一小时的，可以整段认领。每人两小时仅是常见预约方式，不作为网站硬性限制。
- 认领只更新对应范围的约场人和场费垫付归属。沿用原来的 `advancedBy`、`handovers`，不会拆出新场地，不改变接龙人数、场费总额、分摊比例、比赛或预约起止时间。
- `Booking.claims` 保存已认领区间、球友和时间。未认领的登记人可以被实际约场人替换；已经被其他球友认领的区间不能覆盖。自己的相邻时间可以继续认领。
- 接口从存储账号确定本人，不信任提交的角色、组织者身份或其他活动 ID。携带打开表单时的场地和认领快照；场地、价格或认领被改后返回 409，刷新后重新选择。标准请求 ID、修订号及原子保存同时防止并发覆盖和重复提交。

## 组织者纠正与费用

- 群主、管理员或该活动创建者可点「纠正约场人」，选中时间和实际约场成员，包括已经被认领的区间。成员不能代认领或借其他活动的创建者身份纠正。
- 原有场地设置、费用页更正仍有效。修改已认领区间的约场人时同步认领归属；缩短预约时裁掉范围外的认领，延长时不把新增时间自动认领给原球友。
- 已删除、已取消的活动禁止认领；草稿只允许组织者操作。费用尚未确认时允许补认领，即使活动已经结束。
- 一旦存在已确认费用版本，认领入口关闭。组织者使用原费用页的垫付人更正，并重新确认分摊；原确认版本和付款标记不被认领操作改写。
- 认领及纠正写入审计，包含真实操作者、时间范围和修改前后场地。这里只记录预约与垫付归属，不会实际转账。

实现：`lib/domain/booking-claims.ts`、`lib/domain/booking-advancers.ts`、`app/booking-claims.tsx`。沿用[费用垫付规则](FEE_ADVANCES.md)和[场地接龙规则](court-signup.md)。
