# Achievement rank artwork

Mode: built-in imagegen, no fallback CLI.

Five original transparent outer frames are composed in the UI around each existing theme. Generation referenced the existing first-flight artwork for materials and then the bronze frame for geometry. No game artwork was copied. Original generated PNGs are preserved under ignored `work/achievement-ranks/`; deployed finals are `public/badges/ranks/level-1.webp` through `level-5.webp`, 384px, total 169,262 bytes. Center and exterior alpha were checked; resizing and WebP encoding preserve transparency.
