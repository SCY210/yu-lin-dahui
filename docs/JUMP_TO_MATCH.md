# 跳到目标对局

从别处去录分或看比赛时，直接带到那场比赛，不用自己在赛程里翻找。

## 怎么跳

活动页的路由可以带一个目标（`ClubRoute.focus`，网址参数 `match` 或 `round`），只在"分组 / 比赛"标签有效：

- `match`：要看的对局。
- `round`：要看的轮次，打开后定位到这一轮里自己的对局；自己不在场上时定位到这一轮的第一场。

`app/match-focus.ts` 负责定位：目标在轮次标签后面时，先显示那一轮；再把对局卡片平滑滑到屏幕中间，并短暂发光（开启"减少动态效果"时只显示静止的描边）。定位完成后目标从网址里去掉（`ClubNavigation.clearFocus()`，不移动页面），所以刷新、返回、前进不会重复跳转。

"顺便打开录分窗口"是一个单独的一次性请求（`lib/client/score-intent.ts`），不放进网址和浏览历史：录分窗口会在浏览历史里压一层，如果请求存在历史里，关掉窗口时就会被带回来再弹一次，刷新页面也会再弹。对局卡片渲染出来时取走这个请求并打开窗口；没有录分权限的卡片会直接丢弃它；没有卡片取走时，8 秒后自动作废，以后不会意外弹出。

关闭任何弹窗、回到同一个页面时，页面不再跳回弹窗打开时记下的位置（`ClubNavigation.pop`），所以录完分仍停在那场比赛。

没有目标、直接打开"分组 / 比赛"时，每次进入都会自动滑到正在进行的比赛：优先是自己的那场，否则是第一场正在打的。按球友筛选时不自动滑动。

## 其他标签的定位

同样的做法也用在另外三个标签上。路由的目标是一个区块（`focus.section`，网址参数 `goto`），每个区块只属于一个标签：

| `goto` | 标签 | 带到哪里 |
|---|---|---|
| `pay` | 费用 | "转账结算"里自己第一笔待转出的转账；没有就是第一笔待确认收到的；都没有时是分摊总览卡片 |
| `mine` | 活动接龙 | 自己接龙的场地卡片；提醒指明了时段（网址参数 `booking`）时，就是那个时段 |
| `awards` | 玩法 | 赛后 MVP 投票；投票已截止、区块折叠时会先展开 |

`app/section-focus.ts` 负责这三处：等区块渲染出来，平滑滑到屏幕中间（比屏幕还高的区块对齐到顶部，标题不会被滑出去），短暂发光，然后像对局目标一样把目标从网址里去掉。找不到目标（比如没有自己的转账）时也会去掉，不移动页面。

投票截止后，折叠的区块标题从容易误解的"赛后MVP · 结束后开放"改为"赛后MVP · 评选结果"。

## 哪些入口会跳

| 入口 | 跳到哪里 |
|---|---|
| 首页"需要你处理"里的"比分待录入" | 那场比赛，并打开录分窗口 |
| 首页进行中活动卡片上自己那场的"录比分"、其他场地的录分按钮 | 那场比赛，并打开录分窗口 |
| 首页"查看本场对局" | 正在进行的比赛（自己的优先） |
| 其他页面底部的"你有 N 场对局待录比分 · 去录分" | 自己那场比赛，并打开录分窗口 |
| 提醒中心的"轮到你上场了" | 那一轮里自己的对局 |
| 设备推送"轮到你上场了" | 同上（推送里带上轮次 ID，`public/sw.js` 拼进网址） |
| 直接打开"分组 / 比赛"标签 | 正在进行的比赛 |
| 首页"去投 MVP"、"已投票 · 看看结果"、"查看本场结果" | 赛后 MVP 投票（`awards`） |
| 首页"需要你处理"里的"候补转正" | 自己接龙的场地（`mine`） |
| 首页欠款与待收款、"我的"钱包页、我的费用列表 | 自己的转账（`pay`） |
| 提醒中心和设备推送：费用确认 | 自己的转账（`pay`） |
| 提醒中心和设备推送：MVP 投票已开放 | 赛后 MVP 投票（`awards`） |
| 提醒中心和设备推送：报名成功、候补、候补转正、时间调整 | 那个时段的场地卡片（`mine` 加 `booking`） |

推送里的目标由服务端按提醒类型给出（`reminderFocus`，`lib/reminder-contract.ts`），`public/sw.js` 只接受与标签对应的区块和安全的 ID，再拼进网址。点击推送时的网址白名单也放行了 `round`、`goto` 和 `booking`：以前白名单不认 `round`，点"轮到你上场了"的推送会退回"我的"页面。

以前首页的录分按钮是在首页上直接弹出录分窗口；现在先带到比赛所在的赛程，再弹出窗口，录完能直接看到这一轮其他场地的情况。

## 验证

`tests/navigation.test.ts` 覆盖目标的解析、网址往返、只在"分组 / 比赛"标签有效、`clearFocus()` 不移动页面，以及关闭弹窗不移动页面；`tests/score-intent.test.ts` 覆盖录分请求只能被自己那场取走；`tests/match-focus.test.ts` 覆盖目标的选择（指定对局、轮次里自己的对局、自动选正在进行的自己那场）；`tests/home-today-ui.mjs` 覆盖首页录分按钮带上活动和对局；`tests/push.test.ts` 覆盖推送网址带上轮次和区块、点击后打开的就是这个网址；`tests/reminders.test.ts` 覆盖每类提醒的目标；`tests/navigation.test.ts` 还覆盖区块目标只在自己的标签有效。
