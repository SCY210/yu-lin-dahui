# 跳到目标对局

从别处去录分或看比赛时，直接带到那场比赛，不用自己在赛程里翻找。

## 怎么跳

活动页的路由可以带一个目标（`ClubRoute.focus`，网址参数 `match` 或 `round`），只在"分组 / 比赛"标签有效：

- `match`：要看的对局。
- `round`：要看的轮次，打开后定位到这一轮里自己的对局；自己不在场上时定位到这一轮的第一场。

`app/match-focus.ts` 负责定位：目标在轮次标签后面时，先显示那一轮；再把对局卡片平滑滑到屏幕中间，并短暂发光（开启"减少动态效果"时只显示静止的描边）。定位完成后目标从网址里去掉（`ClubNavigation.clearFocus()`，不移动页面），所以刷新、返回、前进不会重复跳转。

"顺便打开录分窗口"是一个单独的一次性请求（`lib/client/score-intent.ts`），不放进网址和浏览历史：录分窗口会在浏览历史里压一层，如果请求存在历史里，关掉窗口时就会被带回来再弹一次，刷新页面也会再弹。对局卡片渲染出来时取走这个请求并打开窗口；没有录分权限的卡片会直接丢弃它；没有卡片取走时，8 秒后自动作废，以后不会意外弹出。

关闭任何弹窗、回到同一个页面时，页面不再跳回弹窗打开时记下的位置（`ClubNavigation.pop`），所以录完分仍停在那场比赛。

没有目标、直接打开"分组 / 比赛"时，每次进入都会自动滑到正在进行的比赛：优先是自己的那场，否则是第一场正在打的。按球友筛选时不自动滑动。

## 哪些入口会跳

| 入口 | 跳到哪里 |
|---|---|
| 首页"需要你处理"里的"比分待录入" | 那场比赛，并打开录分窗口 |
| 首页进行中活动卡片上自己那场的"录比分"、其他场地的录分按钮 | 那场比赛，并打开录分窗口 |
| 首页"查看本场对局" | 正在进行的比赛（自己的优先） |
| 其他页面底部的"你有 N 场对局待录比分 · 去录分" | 自己那场比赛，并打开录分窗口 |
| 提醒中心的"轮到你上场了" | 那一轮里自己的对局 |
| 设备推送"轮到你上场了" | 同上（推送里带上轮次 ID，`public/sw.js` 拼进网址） |
| 直接打开"分组 / 比赛"标签 | 正在进行的比赛 |

以前首页的录分按钮是在首页上直接弹出录分窗口；现在先带到比赛所在的赛程，再弹出窗口，录完能直接看到这一轮其他场地的情况。

## 验证

`tests/navigation.test.ts` 覆盖目标的解析、网址往返、只在"分组 / 比赛"标签有效、`clearFocus()` 不移动页面，以及关闭弹窗不移动页面；`tests/score-intent.test.ts` 覆盖录分请求只能被自己那场取走；`tests/match-focus.test.ts` 覆盖目标的选择（指定对局、轮次里自己的对局、自动选正在进行的自己那场）；`tests/home-today-ui.mjs` 覆盖首页录分按钮带上活动和对局；`tests/push.test.ts` 覆盖推送网址带上轮次。
