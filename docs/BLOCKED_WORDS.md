# 屏蔽词管理

入口：「我的 → 管理员设置 → 屏蔽词管理」。群主和其他管理员均可添加、删除；普通成员及普通活动创建者不能修改全群词库。默认空词库，不预设词语。

每个命中的Unicode字符显示为一个 `*`，英文不区分大小写，特殊字符按普通文字匹配。支持词语重叠，避免较长或重叠词的尾部漏出；支持最多200个词，每词50个Unicode字符，重复词自动合并。

处理昵称、群名、口号、打法、装备说明、活动标题与备注、报名及场地接龙备注、照片说明、场地/球馆名称与地址和费用/日志中的说明文字。系统代码、账号登录信息、ID和数字不参与替换。导航链接由服务器按原始地址生成，编辑未变更的遮盖字段时服务器保留原始数据，避免影响地图、场地匹配或计算。

屏蔽在服务端生成俱乐部视图时执行，因此普通读取接口与网站展示保持一致，旧内容也按当前词库遮盖。原始资料保留，修改词库不批量改写历史内容。管理员可导出原始资料备份；词库本身只出现在管理员视图。

词库保存在现有settings JSON中，无新增数据库表或迁移。写入使用既有登录、同源检查、revision和唯一提交事务门；并发修改返回冲突，不覆盖他人的词库。词库变化会增加revision，使条件读取缓存失效。

验证包含字面匹配、大小写、Unicode、重叠词、词库上限、管理员/群主权限、成员拒绝、服务端视图遮盖、原始数据保留与删除词后的展示恢复。
