# 接龙球友共同录分与输赢积分

已在活动接龙的登录球友（正式、候补均包括）可在「分组 / 比赛」录入或修正已开赛对局的实际比分。活动创建者、管理员仍可录分；取消全部接龙、未接龙或只代报朋友的账号不因此获得权限。录分权限不扩大到排场、开赛、费用管理、作废等操作。界面与服务器使用同一 `canRecordScore` 判断，嵌套比赛 ID 必须从持久化数据找到所属活动。

榜单积分为各计分小局的赛季积分之和：赢 3、输扣 1，赢修为高 50 / 150 分以上的对手另加 1 / 2（见 [REALM_PROGRESSION.md](REALM_PROGRESSION.md)）。季度、年度榜累加实际比赛所属月份的赛季积分与群主手动加分。修为根据比赛结果按小局回放，与赛季积分分开计算。完整自由赛不增减榜单积分。

保存比分按完整比赛记录重新聚合榜单及回放 Elo，不把结果增量重复写入。修正比分会撤销旧结果影响；作废则去掉该对局增减分，保留手动加分记录。改单局数据时，汇总比分也从验证过的小局计算，不能提交一组汇总比分与另一组实际小局。

一次性 `signed-v1` 维护升级把默认规则及马德里当前月份的负局分改为负数（旧 3 → −3，旧 0 → −3，已有负值保留）。过去月份保持原规则；当前榜单自动重算。升级有审计记录，与版本提交在同一个 D1 事务内，重复执行不覆盖管理员以后设置的规则。

验证：`match-scoring.test.ts` 覆盖旧接龙、场地接龙、候补、取消/跨活动/代报权限、胜负积分、改分、作废、修为结算时机及规则升级。`match-scoring-api.mjs` 使用真实 API/store 与内存 SQLite，检查重复请求、并发冲突、回滚、缓存失效和规则升级；同时渲染真实比赛卡片，检查接龙球友确实看得到录分入口。所有数据为隔离的虚构记录，未在生产添加测试比赛。
