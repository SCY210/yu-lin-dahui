# 平抽女王专属「粉粉水族馆」

水族馆主题以用户上传的粉色美西螈为动物参考，使用内置 ImageGen 生成美西螈、Loopy与卡皮巴拉横幅，以及透明吉祥物和伙伴贴纸。视觉使用奶油粉、覆盆子粉、珍珠白，圆角卡片与柔和阴影；正文使用深莓色以保持可读性。图片不含页面文字；手机上动物位于横幅下部，文字与按钮保留独立空间。

群主及服务器数据库中固定账号 `account:2decd719-99de-4679-9f4d-897f39f818ce` 与球友 `ca023b58-7c95-4fa0-89f8-6a85f27ed1dd` 的绑定可启用主题。不按昵称判断，其他管理员没有此权限。群主身份来自服务器持久化 ownerAccountId（兼容既有群主固定身份），并要求账号仍具管理员权限。她默认进入粉粉水族馆；群主可在主题选择中启用，两人都可以切回通用主题。

根布局服务端确认权限后才传递主题选项并加载专属样式。样式 `/api/theme/aquarium` 和图片 `/api/theme/aquarium/art` 每次请求均验证现有登录身份及数据库账号绑定；匿名为401，其他账号为403。返回 private/no-store，避免设备切换账号后共享缓存。专属偏好使用独立设备存储键，群主使用单独的主题偏好键，其他账号继续使用原有通用主题偏好。

图片放在 `assets/private-aquarium/`，通过 `scripts/encode-aquarium-art.mjs` 编码到 Worker 服务端模块。图片和完整样式不放进公共静态目录，修改 localStorage、直接访问素材地址或改名不能获取专属主题。没有修改账号权限、登录逻辑或网站访问范围。

生成素材：横幅2172×724，透明吉祥物1254×1254；WebP发布素材约124KB、65KB及99KB。最终提示词见 `QUEEN_AQUARIUM_PROMPTS.txt`。重新编码命令：`node scripts/encode-aquarium-art.mjs`。

验证：`node tests/theme-access-api.mjs` 检查匿名、其他管理员、同昵称、错误绑定及失效账号无法获得CSS和素材，并检查正确绑定与素材格式。还需通过项目测试、类型检查、构建和手机布局检查。
