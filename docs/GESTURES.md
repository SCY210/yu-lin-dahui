# 手势与页面切换动画

网站主要在手机上使用，这里说明两种滑动手势和页面切换时的动画。

## 左缘右滑返回

- 从屏幕最左边 28 像素以内按下，向右滑动：一个圆形箭头跟着手指出现；滑过 72 像素后圆圈变成实心，这时松手就返回上一步。没滑够就松手，什么也不发生。
- 「返回」和手机的返回键是同一件事：有弹窗时先关弹窗，否则回到上一个页面，并恢复原来的滚动位置。已经在应用内的第一页时，手势不出现，不会把人带出网站。
- 手势要基本水平：竖着滚动时手指偏了一点不会触发。
- 输入框、裁判记分台、实时比分大屏，以及标了 `data-no-swipe` 的区域不响应这个手势，避免记分时误触。
- 两个主题都有这个手势；圆形指示在水墨主题下是宣纸底金边，变实心时是朱砂色。

添加到主屏幕后，iPhone 没有系统自带的返回手势，这个手势补上了这一点。在浏览器里，系统自己的边缘返回手势照常工作。

## 活动页左右滑动切换页签

- 在活动详情页的内容上左右滑动（超过 64 像素，并且明显比上下移动多），切换到相邻的页签：活动接龙、分组 / 比赛、费用、玩法。到了第一个或最后一个就不再动。
- 弹窗里、页签栏和底栏上、输入框里，以及本身能横向滚动的区域（对阵图、表格、头像列表）不触发，这些地方的横向滑动留给它们自己。
- 两个主题都有这个手势。

## 页面切换动画

只在水墨主题下生效（`docs/XIUXIAN_FX.md`）。

- 进入新页面时，内容从右侧滑入并由模糊变清晰，像水墨晕开；返回时从左侧滑入。顶栏和底栏不动。
- 切换活动页签时，只有页签下面的内容滑动，方向跟页签的先后顺序一致。
- 动画约 0.3 秒，只改一个属性来触发，不重新加载页面内容。系统开启「减少动态效果」时没有动画。

## 实现

- 判断逻辑是纯函数，在 `lib/client/swipe-gestures.ts`；触摸监听和返回指示在 `app/swipe-gestures.tsx`。
- `ClubNavigation`（`lib/client/club-navigation.ts`）记录最近一次是前进还是返回（`direction`），以及应用内还能不能返回（`canGoBack`）。
- `lib/client/page-transition.ts` 在路由变化时给页面外壳标上 `data-nav`，样式在 `app/xiuxian-fx.css`。
- 测试：`tests/gestures.test.ts`。
