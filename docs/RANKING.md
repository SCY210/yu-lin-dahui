# 排行榜更新

季度 / 年度榜和首页榜单摘要加入球友头像。上传过头像时展示真实图片；没有头像或图片加载失败时展示昵称首字默认头像。排行榜顶部突出前三名，完整列表展示头像、积分、计分/实际场数、胜负、胜率与场均净胜分，并标记本人。

入榜最低场数已取消，有正式账号的启用球友在同一榜单；代报名邀请来的朋友不入榜。其报名、比赛和费用记录保留；为原档案开通正式账号后，可按原比赛记录入榜。旧赛季保存过最低6场等规则也不再分成正式/暂定榜；本周期0场的球友会显示0分及“本季度暂无计分赛”。积分、勝率与净胜分的同分规则保留，完全相同仍并列。

入榜门槛取消时没有改变历史比赛事实。现在积分为赛季积分之和（每局输 1、赢 3，另有强弱加成），没有月计分上限，也不再提供月榜，见 [REALM_PROGRESSION.md](REALM_PROGRESSION.md)。原规则的minimum字段为兼容旧数据保留，新默认值为0，设置页不再提供入榜门槛设置。

排名页分“双打榜 / 单打榜”：双打榜只统计 2 对 2 比赛并计入群主调整；单打榜只统计一对一比赛，规则见 [SINGLES_RANKING.md](SINGLES_RANKING.md)。

TypeScript检查通过；35项算法回归通过，其中新增旧赛季最低6场、1场/0场球友同榜及并列排名验证。浏览器头像、完整榜单和手机排版按本次预览检查。
