# 费用页

活动的「费用」页（`app/fees.tsx`、`app/fee-page.css`）在 2026-11-18 按群主要求重新设计：重点放在最上面，说明文字只留一句，重复的信息删掉，不再用一层层折叠栏。两个主题都生效，水墨主题的样式在 `app/xiuxian-fx.css`。

页面从上到下是三张卡片，然后是本次用球和说明按钮。

## 总览

1. **状态和合计**：左边一枚状态标签，右边是「N 人 · 合计 €x」。状态只有四种：
   - 预估：活动还没结束，按接龙时段预估；
   - 未确认：可以确认了，还没确认；
   - 有更新 · 待重新确认：确认过之后费用又变了（只有管理者看到）；
   - 已确认 · 第 N 版。
2. **我的分摊**：左边是「我的分摊」和付款状态（以及「标记已付款」），右边是大字金额，不再单独用一行放状态。自己代报名的朋友各占一行，标「代报名」。有转账时这里只写金额，不写状态：状态在下面自己那笔转账上，不重复。
3. **一句提示**（需要时才有）：例如「按接龙时段预估，活动结束后确认。」「活动结束后可以确认。」「已忽略一次费用变化，仍按这一版付款。」
4. **没人分摊的钱**（只有管理者看到）：例如「€3.92 没人分摊：1号场 12:00–12:34。缩短场地时间或改为群补贴后才能确认。」
5. **管理按钮**（宗主、副宗主和活动创建者）：只放下一步要做的事。还没确认时是「保存草稿」「确认分摊」并排；确认后有人没付就是「提醒未付款（N 人）」，都付了就写「全部已付款」。确认后不再显示灰色的「已确认」按钮，状态印章已经写明。其余不常用的操作（复制分摊金额、撤回第 N 版、忽略这次更新、查看被忽略的更新）收进右边的「更多」，点开是一个操作弹窗。
6. **转账**：确认后有垫付时出现（`app/fee-transfers.tsx`）。标题旁是「复制明细」，下面直接是每笔一行，不再加说明句：转给谁已经写在每一笔上。每笔：左边「谁 → 谁」，自己写成「我」；右边是金额；和自己有关的那笔多一行对方电话和「复制」，没填时写「某某 还没填电话」；最下面左边是「待转 / 已转」，右边一个按钮（标记已转、确认已收到或撤销）。已转的那笔变灰。谁垫付了多少不在这里列，账目里每一项已经写着约场人和球主；分摊取整多收或少收的说明只给管理者看。其他人的转账仍收在「其他人的转账 · N 笔」里。
7. **收款方式与收款人**：管理者看到一个二选一：「无统一收款人」和「统一收款人」，默认是前者，大家按转账结算直接转给约场、出球的人。选「统一收款人」后，同一位置出现一个「选择收款人」按钮，点开弹窗：常用收款人排成一列，宗主和副宗主在前，其他用过的在下面，点一下就选中；保存者本人和副宗主可以按 × 删除；最下面是「新的收款人」。选好后按钮消失，原位置换成一张高亮卡片，大字写收款人名字，下面是电话和「复制」，管理者在卡片上点「更换」重新打开弹窗。改回「无统一收款人」会清除这场活动的收款人（`feeRecipient` 命令带 `none: true`），常用收款人保留；已确认的分摊会显示有更新，重新确认后转账结算按新的方式生成。宗主、副宗主和活动管理者都可以改。球友只在设了收款人、而且还没有转账结算时看到这张卡片；有转账结算后，转给收款人的那笔已经写着名字和电话，卡片不再重复显示；管理者仍看到卡片（为了「更换」），但只留名字，不再重复电话。

## 每人分摊

每人一行：名字和金额；下面一行是参加分钟数和有金额的项目，例如「146 分钟 · 场地 €4.22」，0 元的项目不列。代报名的朋友标「代报名」，有费用豁免的标出豁免内容（例如「球费群补贴」）。管理者每行有「豁免」按钮，直接设置这个人的费用豁免，不再有单独的豁免列表。

## 账目

标题右边写场地、球、群补贴、待分配的合计（0 元的不列，场地始终列出）。下面每个场地预约、耗球记录和其他费用各占一行：名称、时间、约场人或球主，右边是金额。管理者点一行，弹出这一项能调整的内容（约场人、由谁承担、修正预约；球主或垫付人、时段调整、移除），不再在每一项下面排一串按钮。最下面一行是分摊方式和「修改」，以及「记录耗球」「其他费用」两个按钮。

## 其他

- 「本次用球」卡片不再收在折叠栏里；还没有候选球时，只有能管理的人看得到它。
- 最底下是「费用怎么算」说明按钮，详细的计算规则都在里面。

- 「费用合计与规则」里的三张统计卡和整段分摊规则说明（合计并进「账目」标题，规则在「费用怎么算」里）。

- 收款人一节的长段说明，以及每人分摊行里重复的「分摊金额」字样。
