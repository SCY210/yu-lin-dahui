# 每周球局成长与小局计分

## 常用一局一轮

每局结束就记录一次比分，再轮换搭档和对手。录分默认只显示本局比分；三局两胜放在其他比赛形式中，保留旧记录编辑能力。一般15分钟一轮，4小时约16轮是场地总轮次，个人计分按实际参与的轮次，不把轮休或未到场的轮次计入。

## 当前标准

- 积分榜：正式计分小局每胜+10分、每负−3分，积分可为负，默认不再每月只计12场。季度与年度仍按各月规则汇总，先积分、再小局胜率、再局均净胜。
- 统计：三局两胜2∶1按2胜1负、3小局计算；获胜者17分、另一方4分，胜率分别66.7%和33.3%。球员档案、近期状态与搭档对位胜率使用小局口径。隐藏Elo仍以整场胜负更新一次，原始实力、初值、调整系数和匹配逻辑不修改。
- 成长：每正式胜局10修为、负局3修为。当天第一次完成正式局额外10修为，仅实际比赛记录触发。马德里自然日最多前12小局获得成长，多活动、多场地共享日限；积分榜没有此成长日限。
- 缺席不会扣修为，不要求全群到场。友谊、应用让分、取消、弃权、未完成、未来完赛不增加成长修为。高级别之后累计修为继续显示。

## 活动结束后结算

比赛过程中不升降境界。属于某个活动的比赛，在该活动结束前不计入修为、境界、阶段与进度；活动结束后在下一次读取时一次结算，无需任何人手动操作或写入数据。

- “结束”与活动状态使用同一口径（`lib/domain/event-lifecycle.ts`）：到达活动结束时间（多场地以最后一个时段为准）自动结束，或创建者提前标记结束；取消的活动、以及任何状态已过结束时间的活动也视为已结束。延长场地使结束时间推后、或在结束时间前恢复为进行中，则继续等待结算。删除活动不提前结算，已完成的成绩仍按结束时间计入。
- 结算按整场结束时间、比赛编号和小局顺序重放，当天首局奖励、日限和马德里日期全部沿用完赛时间，所以结算结果只取决于完整记录，与读取时机无关；结束后补录的比分立即结算。
- 找不到所属活动记录的旧比赛，仍在完赛后即计入。友谊赛、应用让分的对局本来就不产生修为，不受影响。
- 积分榜积分、胜负与胜率仍在录入比分后即时更新；只有修为境界等待活动结束。档案与“我的”页面显示“另有 N 小局待活动结束后结算”。
- 隐藏实力分仍在每次录分后重放，自动分组和让分建议使用最新实力；比赛卡片上给成员看的“队伍参考实力”档位改用已结算比赛重放的实力，活动中同样不变。
- 读取缓存在有成绩活动的结束时刻失效，结束后不会继续显示旧境界。

## 晋级节奏

炼气0，筑基60，金丹180，元婴400，化神800。每周个人6小局3胜3负，一次获得21榜单分、49成长修为。新成员从0开始，约2次到筑基、4次到金丹、9次到元婴、17次到化神；只是假设每次都实际录入这些有效比赛的计算示例。已有筑基球友从至少60继续，约再3次同样活动到金丹。低胜率球友也能逐步成长，缺席时进度保持。

榜单积分按胜负加减，胜局奖励与负局扣分可以使总分低于0；榜单展示小局数和胜率，成长境界不作为真实强弱或配对依据。

## 旧数据升级

首次已登录访问时通过现有D1乐观事务维护流程一次性应用。旧成长规则迁移将旧默认每胜3、每负0、月上限12（或已取消上限0）升级为10/3/0；随后 signed-v1 将默认及本月负局分改为−3，之前月份保留历史规则；自定义其他分值或上限数字保持，上限统计单位统一为实际小局。历史月份按对应更新后规则重算榜单，比赛比分不修改，旧规则与基准修为在管理员审计保留。

旧实力境界阈值1100/1232/1300/1380映射到新筑基/金丹/元婴/化神门槛。冻结补差额 = max(0,旧境界新门槛 − 升级时回算的历史成长修为)。后续总修为 = 补差额 + 实际比赛回算修为；不会持续取历史门槛最大值让增长停滞，也不会把旧境界门槛和历史修为重复相加。升级不改变精确实力、成员权限或原始比分。

新成员从炼气0修为开始。成长根据完整记录派生，按整场结束时间、比赛编号和实际小局顺序重放；没有逐局时间，所以整场各小局统一归入整场完赛的马德里日期。当天首局奖励与日限随改分、作废、补录自动回算。真正纠正历史记录可能调整境界；缺席和普通输球不会扣去已有修为。缺少逐局比分的旧单场记录仅按一局保留，不估计额外小局。
