# 每周球局与小局计分

## 常用一局一轮

每局结束就记录一次比分，再轮换搭档和对手。录分默认只显示本局比分；三局两胜放在其他比赛形式中，保留旧记录编辑能力。一般15分钟一轮，4小时约16轮是场地总轮次，个人计分按实际参与的轮次，不把轮休或未到场的轮次计入。

## 当前标准

- 修为与境界：每个计分小局按 Elo 结算（每人从 1000 起，新手期前 20 局 K = 32，之后 K = 16，双打按两队平均分计算、同队两人加减相同）。完整规则、境界门槛、保级缓冲和模拟结果见 [REALM_PROGRESSION.md](REALM_PROGRESSION.md)。
- 积分榜：季度 / 年度积分 = 周期内每个计分小局的赛季积分之和（赢 3、输扣 1，赢修为高 50 / 150 分以上的对手另加 1 / 2；双打榜另加群主手动调整）；没有月度小局上限，也没有月榜。先积分、再小局胜率、再局均净胜。
- 统计：三局两胜 2∶1 按 2 胜 1 负、3 个小局计算，每一局分别结算修为；胜率分别为 66.7% 和 33.3%。球员档案、近期状态与搭档对位胜率使用小局口径。自动分组用修为的同一公式只回放双打小局，单打不改变分组实力。
- 缺席既不加分也不扣分，不要求全群到场；连续 3 个月没有计分小局，修为才回到 1000 重新定级。友谊赛、应用让分、取消、弃权、未完成、未来完赛不改变修为。

## 活动结束后结算

比赛过程中不升降境界。属于某个活动的比赛，在该活动结束前不计入可见修为、境界、阶段与进度；活动结束后在下一次读取时一次结算，无需任何人手动操作或写入数据。

- “结束”与活动状态使用同一口径（`lib/domain/event-lifecycle.ts`）：到达活动结束时间（多场地以最后一个时段为准）自动结束，或创建者提前标记结束；取消的活动、以及任何状态已过结束时间的活动也视为已结束。延长场地使结束时间推后、或在结束时间前恢复为进行中，则继续等待结算。删除活动不提前结算，已完成的成绩仍按结束时间计入。
- 结算按整场结束时间、比赛编号和小局顺序重放，所以结果只取决于完整记录，与读取时机无关；结束后补录的比分立即结算。保级缓冲在每次活动结算后判断一次。
- 找不到所属活动记录的旧比赛，仍在完赛后即计入。
- 积分榜积分、胜负与胜率仍在录入比分后即时更新（标注“含进行中”）；只有修为与境界等待活动结束。档案与“我的”页面显示“另有 N 小局待活动结束后结算（暂计 ±X 分）”。
- 分组实力按修为公式只回放双打小局，每次录分后重放，自动分组和让分建议立即使用；比赛卡片上给成员看的队伍境界按已结算的平均修为显示，活动中同样不变。
- 读取缓存在有成绩活动的结束时刻失效，结束后不会继续显示旧境界。

## 旧数据

2026-10 起停用累计成长规则，`elo-v1` 维护步骤（`enableEloRealms`）一次性写入版本标记和审计；所有球友从 1000 起按全部已有比赛回算，旧的成长底分（`cultivationBase`）与初始实力不再影响可见境界。各月 `win` / `loss` / `cap` 设置保持存储但不再参与积分，历史季度与年度按新规则重算。比赛比分不修改。
