# Venues and Google Maps

The venue directory contains Antonio Diaz Miguel, Daoiz y Velarde, Felix Rubio, Fernando Martin, Gimnasio Moscardo, Hortaleza, La Elipa, La Fundi, Marques de Samaranch, Orcasur, and Pradillo. Source records preserve accented names.

Selecting a recognized venue fills its canonical address. Create/edit validation also normalizes it. Historical custom venues remain as current records and are not rewritten in bulk. Recognized venue display/map links use directory addresses.

Venue/address links open Google Maps externally, and copied signup text includes the address and map URL. URLs follow the [official Maps URL format](https://developers.google.com/maps/documentation/urls/get-started); no Maps API key or paid service is required.

Addresses were checked during the original 2026-10-04 implementation.
