# 赛后球友评选

活动 → 玩法 → 本场球友评选。四个奖项分别切换候选卡片，展示头像、票数、个人评选进度与当前领先/并列结果，不再在一屏重复四组名字按钮。

每个账号、每个活动、每个奖项一票，不可自投。选其他球友即改投；「撤回本项」撤销自己的选票。过时的撤票目标与现有选择不一致时返回 409，避免误删新选择。参与者、创建者、管理员可投票。到达活动预定结束时间后自动显示为已结束并开放评选，多场地活动以活动汇总的最后结束时间为准，不需要手动结束。没有录完的对局仍保留原状，参与球友可补录比分并按原规则计分；不会伪造比分或清除对局。草稿、取消、删除及未开场活动不开放评选。提前手动结束仍须无进行中对局。活动状态按服务端时间推导，无需后台定时任务或持久化状态写入；在线页面在开始/结束边界更新，手机唤醒后重新核对，客户端不能绕过服务端时间与权限。延长预定活动时间后采用新结束时间。

正式报名、已到场与已完成真实比赛的启用球友作为候选；未来比赛不增加实际参加资格。别人投票的账号和编码账号的选票 ID 不在成员投影中公开；页面仅展示汇总与自己的选择，管理员审计权限保持原规则。

验证：结束时间边界、取消/草稿/删除、延长时段、读缓存失效、未录完比分仍可投票且补录继续计分，以及活动投票权限/撤回/改投/并列与资格回归，`award-voting-api.mjs` 使用真实 API/store + 内存 SQLite 检查幂等、过时撤票、权限、匿名投影和事务回滚。新组件做服务端渲染检查；未声称实测手机浏览器。
