# 赛后球友评选

活动 → 玩法 → 本场球友评选。四个奖项分别切换候选卡片，展示头像、票数、个人评选进度与当前领先/并列结果，不再在一屏重复四组名字按钮。

每个账号、每个活动、每个奖项一票，不可自投。选其他球友即改投；「撤回本项」撤销自己的选票。过时的撤票目标与现有选择不一致时返回 409，避免误删新选择。结束活动后的参与者、创建者、管理员可投票；未开始、进行中、取消或已删除的活动遵守原有关闭规则。创建者可以在实际开场后、无进行中比赛时通过确认结束活动来开启评选。

正式报名、已到场与已完成真实比赛的启用球友作为候选；未来比赛不增加实际参加资格。别人投票的账号和编码账号的选票 ID 不在成员投影中公开；页面仅展示汇总与自己的选择，管理员审计权限保持原规则。

验证：活动投票权限/撤回/改投/并列与资格回归，`award-voting-api.mjs` 使用真实 API/store + 内存 SQLite 检查幂等、过时撤票、权限、匿名投影和事务回滚。新组件做服务端渲染检查；未声称实测手机浏览器。
