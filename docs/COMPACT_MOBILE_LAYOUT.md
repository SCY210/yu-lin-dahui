# 手机紧凑布局

主要操作和简短摘要保持可见。次要列表和说明用明确的原生折叠项收起，而不是用 CSS 隐藏内容或缩小字号。

| 页面 | 默认可见 | 按需展开 |
| --- | --- | --- |
| 场地接龙 | 场地和时间、名额、接龙按钮、前六个球友头像链接 | 正式和候补名单、个人修改；有待处理的取消申请时名单默认展开 |
| 实时排场 | 当前比赛和录分按钮、自己的轮休意愿 | 其他球友、已完成的比赛和搭档设置 |
| 预排赛程 | 进行中的轮次（展开），下面一排全部轮次的标签，颜色和轮次一致（已结束绿色、进行中红色带小红点、未开始原色）；没有轮次进行中时显示下一轮 | 点标签查看那一轮，一次显示一轮，再点一次收起；点进行中的标签滑到上面那一轮 |
| 费用 | 确认状态、自己的金额、确认和通知按钮、收款人，集中在一张卡片里；和自己有关的转账每笔一行；超过 6 笔且有已完成的时，分"待处理 / 已完成"两个标签 | 每人完整分摊、费用合计与规则、费用编辑和豁免 |
| 首页费用卡片 | 只有一个活动要付时显示完整内容；其余情况每张卡片一行摘要（活动数、人数、合计） | 点摘要打开收付款页（`page=money`），列出全部活动和付款人 |
| 排行榜 | 每位球友一行：名次、头像、名字和境界、计分局数，积分和胜率在右侧 | 积分明细 |
| 球员主页 | 身份、境界、口号摘要和允许的编辑按钮 | 个人资料和风格、装备和照片、统计和成就 |
| 我的 | 头像和境界、成就入口、最新一份个人分摊、设置入口 | 成就簿（单独页面）和更早的已确认分摊 |
| 玩法 | 进行中的赛后 MVP 投票、擂台和王者局信息 | 普通玩法设置和赛前 MVP 预览 |

金额、费用确认、录分权限、账号限制、个人主页视角和导航都不变。球员头像和名字链接仍使用原有的导航历史。不需要数据迁移。其他原生折叠项保留原有的延迟挂载行为。

## 减少下滑（2026 年 11 月）

原则：不是把内容硬折叠起来，而是按功能换成更合适的界面。

- 要处理一批事情的地方换成**新页面**：首页的付款、收款和逾期卡片只留一行摘要，完整列表和标记按钮放到收付款页。
- 一次只看一项的地方换成**标签**：赛程里的轮次、费用页里待处理和已完成的转账。
- 本来就只需要扫一眼的列表换成**更紧凑的排版**：排行榜每人一行，转账按钮放进同一行。
- 用时才看的细节改成**点一下才显示**：场地时间占用只在点时间条或有空档时列出名单，不再在每片场地下重复整份名单。

用一个虚构俱乐部（22 位球友、四场已结束但没收齐钱的积分赛、一场 12 轮预排的进行中积分赛、一场即将开始的活动）在 390 px 宽度下实测，按一屏 844 px 计：

| 页面 | 之前 | 之后 |
| --- | --- | --- |
| 首页（收款人视角） | 6.9 屏 | 1.6 屏 |
| 排行榜（22 人） | 6.4 屏 | 3.9 屏 |
| 分组 / 比赛（12 轮预排、第 1 轮进行中） | 5.8 屏 | 3.5 屏 |
| 费用（收款人，17 笔转账） | 4.6 屏 | 3.8 屏 |
| 活动接龙（创建者视角） | 3.5 屏 | 2.8 屏 |

验证：`tests/compact-sections-ui.mjs` 使用真实的 React 组件，检查折叠和展开、个人主页链接、报名修改、自己的轮休修改、费用通知内容、完整分摊入口，以及最新确认版本和历史版本的选择。原有的个人主页、录分、接龙和接口测试仍然必须通过。这些检查使用隔离的虚构数据，不写入生产环境。CSS 保留主题变量、可读的文字和触控尺寸；浏览器和真机渲染结果要与组件测试分开报告。

## 已完成对局的胜负

已完成的对局一眼看出谁赢（`app/match-card.tsx`、`app/compact-matches.css`）：胜方整队有金色描边和淡金底，右上角盖一个红色"胜"字印章；胜方比分放大并上色，败方比分和整队变淡。队名标签只写"A 队 / B 队"，"· 胜"留给读屏软件读出。两个主题配色不同（水墨主题用朱砂印章和赭金描边）。没有使用 `color-mix()` 等较新的特性，旧版 iOS Safari 也能正常显示。

## 积分赛开关

"分组 / 比赛"标签顶部不再有单独的"积分赛 / 普通活动"卡片。能改的人（群主、管理员，以及本活动的测试员创建者），在第一局开打前，会在"分组规则""比分与计分"右边看到"改为普通活动"或"开启积分赛"按钮（`app/event-ranking.tsx`），点开后仍要确认。其他人什么都不显示；本活动是不是积分赛，看活动标题旁的积分赛徽章。

## 俱乐部顶栏

进入俱乐部后，顶栏是一块紧凑的区域，让内容在手机上从更高的位置开始：

- 主题选择器是顶栏图标行里的一个图标按钮，挨着宝阁和提醒图标。页面上方单独的主题工具栏只出现在俱乐部之外的页面，例如登录页。
- 手机上三个图标是 36 px 的方块，提醒只显示铃铛。它的文字仍然提供给读屏软件，未读数显示在角上。
- 页面渐变和纹理画在根元素上，body 是透明的。以前 body 单独有背景时，顶部会露出一条纯色的根元素颜色：一是被折叠的上外边距露出来，二是在 iOS 状态栏下面也会露出来。
