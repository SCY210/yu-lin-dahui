# 首页与活动列表

首页只显示今天需要处理的事，"活动"标签页才是完整的活动目录。

## 首页（`app/home-today.tsx`、`lib/client/home-today.ts`）

从上到下依次是：

1. **待付费用**（`app/home-unpaid.tsx`）。最新一版已确认分摊里还有未付账单的活动，每个活动一项。成员还替自己代报名的朋友付钱时，这一项会列出每张账单和合计。活动设了收款人时，这一行显示收款人和复制按钮。"标记已付款"按钮不离开页面就为该活动的每张账单记一笔自报付款（`feePaid`）。账单和转账以一行可换行的小标签显示，不再一人一行。要付的活动不止一个时，首页只显示一张摘要卡片（"有 N 场活动还没付款 · 合计"），整张卡片是一个按钮，打开**收付款**页（见下）。
2. **等你收款**和**提醒 3 次仍未付款**（`app/home-fees-owed.tsx`），收款人和管理员看到的别人欠的钱。首页每张只是一张摘要卡片："等你收款：N 场活动"写明未付人数、合计金额和其中已提醒 3 次仍未付的笔数；"提醒 3 次仍未付款"写明活动数和人次。点卡片打开**收付款**页。以前这里把每个付款人逐行列出，一整场活动没付款时，会把进行中的比赛挤到好几屏以下。
3. **待办**（`homeTodos`）：
   - 已经不在进行中的活动里，成员自己的比赛还没录比分（进行中的比赛在它的实时卡片上有"录比分"按钮）；
   - 成员还没报名、报名截止在 `signupSoonHours`（24 小时）以内的开放活动；
   - 最近 `promotionNoticeHours`（24 小时）内从候补转正。

   每个活动每种待办只出现一次，按上面的顺序排列。
4. **进行中的活动**（`liveActivities`）。每个进行中的活动一张突出的卡片，合并它所有的场地。成员正在场上时，卡片写明场地、搭档和对手；否则显示轮休提示。
5. **最近结束**（`recentlyEnded`）。最近 `recentlyEndedHours`（24 小时，只要 MVP 投票还开着）内结束的活动，或组织者提前结束的活动。成员还能投票（`canCastAwardVote`）且还没投时，卡片提供 MVP 投票；否则链接到活动。


## 收付款页（`page=money`，`app/money-page.tsx`）

从首页的费用摘要卡片打开，顶部有"返回首页"，手机返回键也回到首页。依次显示：自己要付的每个活动（账单、收款人和复制号码、"全部标记已付款"或"全部标记已转"），别人欠自己的每个活动（每位付款人和金额，提醒 3 次仍未付的标红，"全部标记已收到"），以及群主和管理员看到的提醒 3 次仍未付款的活动。已经出现在"等你收款"里的付款人，不会在"提醒 3 次仍未付款"里重复列出。点活动标题打开它的费用页。什么都没有时显示"现在没有要付或要收的钱"。

## 首页空状态

什么都没有时，显示一个安静的空状态，链接到"活动"标签页。组件每 15 秒重新计算一次，所以卡片会准时出现和消失，不必重新加载。

## "活动"标签页（`groupEvents`）

即将开始的活动分成：

- **我已报名**（第一组）：成员有有效（未取消）报名的活动；
- **可以报名**：开放报名且未过截止时间；
- **其他活动**：其余即将开始的活动，例如已锁定或已满员的活动。

已结束和已取消的活动收在**历史活动**折叠项里，最新的在前。

## 水墨主题的提示条

`app/wuxia-toast.css` 在 `html.wuxia-theme` 下重新设计 Sonner 提示条：宣纸底色、直角、衬线字体，左侧一条粗边用主题颜料（成功用绿色，错误和普通提示用朱砂色，警告用赭石色）。经典主题保持原来的颜色。

## 顶栏与首页快捷入口

首页和"我的"页上的宝阁卡片换成了顶栏里提醒按钮左边的礼物图标，每个页面都有。它的无障碍名称和悬停提示里写着余额。首页不再显示创建活动、创建比赛和活动指南按钮，它们留在"活动"页上。"我的"页不再列出账号须知的确认记录；记录本身仍按隐私说明保存。

## 在首页给任意场地录分

所有可以给活动录分的人（报名了该活动、组织者或管理员，即服务器的录分权限）都能在进行中活动卡片的每片场地上看到录分按钮，而不只是自己的比赛。活动不在进行中后，它未录分的比赛合并成每个活动一条待办，写明比赛数；点开先打开查看者自己的比赛。只有查看者自己的比赛会自动打开录分表单（`lib/client/score-reminder.ts` 里的 `pendingScores` 和 `pendingOwnScores`）。
