# 三个试用球友的可恢复清理

群主可在「管理员设置 → 球友账号 → 试用账号清理」移除或恢复试用球友01、02、03。操作仅匹配服务端固定的三组账号与球友 ID，并核对登录账号 trial01、trial02、trial03；不接受客户端指定删除目标。其他管理员和成员无权使用。

移除会隐藏对应账号、档案和试用报名，试用账号发出的打法标签投票一并存档，并撤销全部试用登录会话。登录凭据移入私有 trial_credential_archive 表，当前凭据和登录会话被删除，因此移除后无法登录。密码哈希不会写入操作日志、普通俱乐部接口或导出内容。账号和档案快照存入现有管理员操作日志，用于正常恢复流程；数据库新增一张私有凭据存档表。

恢复会同时恢复存档的试用打法标签投票，不覆盖已存在的投票记录。恢复不会覆盖已存在的身份，也不会自动恢复报名，以免夺走已经递补的名额。试用球友需要重新登录、重新报名，并重新选择是否接收通知。账号名被重新使用时拒绝恢复，不覆盖新账号。

若三组身份已改名、晋升管理员、有计分比赛、头像、比赛或费用等其他依赖，或报名已经开始，则拒绝清理，要求先人工核对。未来试用报名移除后按现有规则递补。

所有更新通过现有 D1 save() 的唯一 revision 事务门进行；唯一 revision 插入仍是第一条语句，私有凭据存档、会话和凭据清理在删除账号前执行；账号、档案、报名、审计快照和凭据存档在同一批次保存。并发修改失败后返回冲突，不覆盖其他成员的变更。已有提交标记确保重试不会重复清理。

验证：trial-cleanup.test.ts 覆盖精确目标、群主权限、依赖拒绝、恢复冲突、原报名不恢复和重复操作幂等；发布前执行项目类型检查、测试及构建。
