# 转账结算的展示

费用页的「转账」每笔是一张紧凑的卡片（见 [费用页](FEE_PAGE.md)）。第一行左边是「姓名 → 姓名」，左侧转给右侧，本人显示为「我」，悬停可看完整姓名，名字太长时用省略号；右边是金额。

和自己有关的转账第二行是对方电话。最下面一行左边是「待转 / 已转」，右边是唯一的操作按钮。已转的卡片底色变淡、金额变灰。转账上方不再有说明句和「已垫付」列表：转给谁写在每一笔上，谁垫付了多少写在账目里，都不重复。

保留原有转账金额、付款与收款确认权限、撤销、对方电话、复制明细、其他人转账折叠、长列表的待处理与已完成切换，以及「去付款」定位。这项改动只调整界面结构和样式，不改变费用计算、结算记录或付款操作。

验证：`tests/fee-transfers-ui.mjs` 覆盖左侧付款人、右侧收款人、中间箭头及「我」的显示、名字旁的金额、只有一个按钮的底部一行、不再重复显示收款人和已垫付，并继续验证确认权限、撤销、折叠、长列表及电话。视觉检查使用虚构长姓名与窄屏页面，检查箭头可见性，不访问生产数据。
