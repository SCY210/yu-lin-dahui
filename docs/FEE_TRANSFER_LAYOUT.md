# 转账结算的展示

费用页的「转账结算」每笔使用独立卡片。上方分别标明付款人、收款人，展示双方完整姓名；当前球友在姓名旁另加「我」标记，避免用「我」替代姓名造成复制或对照时难以辨认。长姓名允许正常换行，不截断、不逐字挤成窄列。

下方单独显示「应转金额」、转账状态和确认按钮，姓名不再与金额、状态和按钮争用同一行宽度。手机窄屏把付款人与收款人上下排列，金额及操作区域可换行，按钮至少 44 像素高。宽屏则并排展示双方及方向箭头。

保留原有转账金额、付款与收款确认权限、撤销、收款人电话、复制转账明细、其他人转账折叠、长列表的待处理与已完成切换，以及「去付款」定位。这项改动只调整界面结构和样式，不改变费用计算、结算记录或付款操作。

验证：`tests/fee-transfers-ui.mjs` 覆盖付款人、收款人、完整姓名与自我标记、单独金额与操作区域，并继续验证确认权限、撤销、折叠、长列表及收款信息。视觉检查使用虚构长姓名与窄屏页面，不访问生产数据。
