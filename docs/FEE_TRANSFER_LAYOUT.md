# 转账结算的展示

费用页的「转账结算」每笔使用独立卡片，保留原来的「姓名 → 姓名」箭头展示，左侧转给右侧；本人继续按原样显示为「我」，悬停可看完整姓名。其他球友展示完整姓名并允许换行，箭头在手机和宽屏上始终可见，不改为上下排列的付款人、收款人标签。

下方单独显示「应转金额」、转账状态和确认按钮，姓名与箭头不再与金额、状态和按钮争用同一行宽度。窄屏保留左右箭头关系，缩短「我」一侧占用的宽度，给另一侧姓名更多空间；金额及操作区域可换行，按钮至少 44 像素高。卡片通过留白、圆角、轻阴影及箭头底色区分层次。

保留原有转账金额、付款与收款确认权限、撤销、收款人电话、复制转账明细、其他人转账折叠、长列表的待处理与已完成切换，以及「去付款」定位。这项改动只调整界面结构和样式，不改变费用计算、结算记录或付款操作。

验证：`tests/fee-transfers-ui.mjs` 覆盖左侧付款人、右侧收款人、中间箭头及原有「我」的显示、长姓名、单独金额与操作区域，并继续验证确认权限、撤销、折叠、长列表及收款信息。视觉检查使用虚构长姓名与窄屏页面，检查箭头可见性，不访问生产数据。
