# 段位分与修仙境界（elo-v1）

可见境界和季度 / 年度榜积分都来自同一个“段位分”（FIDE 式 Elo）。原先只增不减的累计成长规则（赢 10、输 3、当天首局奖励、每日上限）已整体停用，界面、说明和代码中不再出现。实现见 `lib/domain/realm-rating.ts`。

## 公式

- 每人从 1000 分起。每个已完成的计分小局单独结算；三局两胜按实际打完的每一局分别计算。
- 预期胜率 `E = 1 / (1 + 10^((对手分 − 自己分) / 400))`，本局变化 `K × (结果 − E)`，赢 1、输 0；四舍五入为整数（正负对称，`roundDelta`）。
- K：每人前 20 个计分小局 K = 32（定级期），之后 K = 16；搭档各按自己的计分小局数取 K。
- 双打按个人计算（群主的选择，`realmPolicy.doubles = 'individual'`）：每人用自己的段位分对比对方两人的平均分。例：A 队 1200 + 900（平均 1050）对 B 队 1050 + 1050，K = 16：A 赢，1200 分 +5、900 分 +11、B 两人各 −8；A 输，1200 分 −11、900 分 −5、B 两人各 +8。
- 单打是同一公式的一对一情形，单打与双打共用一个段位分。

| 分差 | 强方赢 | 弱方爆冷赢 |
| --- | --- | --- |
| 0 | ±8 | ±8 |
| 50 | +7 / −7 | +9 / −9 |
| 100 | +6 / −6 | +10 / −10 |
| 150 | +5 / −5 | +11 / −11 |
| 200 | +4 / −4 | +12 / −12 |
| 300 | +2 / −2 | +14 / −14 |
| 400 | +1 / −1 | +15 / −15 |

（K = 16；定级期 K = 32 约翻倍。双打的“分差”是自己与对方两人平均分之差。功能说明里的表格由 `exchangeRow` 按同一公式生成。）

## 哪些小局计分

`isRatedMatch`：已完成、`monthly` 与 `elo` 都为真、没有已应用的让分、双方都有人且没有同一人、至少一个有效小局、完赛时间不晚于当前时间。所以友谊赛、已应用让分、取消、弃权、进行中和未来完赛的记录都不改变段位分（与原隐藏 Elo / 让分排除规则一致）。重复的比赛编号只计一次；含有已删除球友档案的比赛跳过。

回放顺序完全由历史决定：整场结束时间 → 比赛编号 → 小局顺序；每局的变化都按该局之前的分数同时计算。纠错、作废、补录后从头回放。

## 境界

| 境界 | 段位分 |
| --- | --- |
| 炼气 | 899 及以下 |
| 筑基 | 900–999 |
| 金丹 | 1000–1099 |
| 元婴 | 1100–1199 |
| 化神 | 1200 及以上 |

- 达到门槛立即晋升；降级有 15 分缓冲：已持有的境界只有跌破“门槛 − 15”才失去（元婴低于 1085 才降为金丹）。从更高境界跌落时，落到仍在其缓冲内的最高境界（`settleRealmIndex`）。
- 缓冲按活动判断：一次活动全部结算后检查一次（回放中以活动的最后一个计分比赛为检查点），活动中途短暂跌破缓冲、结束时回到缓冲内不降级。
- 每个境界 100 分分为初期（0–33%）、中期（34–66%）、后期（67–99%）；炼气按 800–899 计算进度，800 以下为 0%。化神 1200–1299 同样分三期，1300 分及以上显示“化神圆满”（100%）。这样化神仍有可追求的目标，而段位分本身继续随胜负变化。
- 计分小局少于 10 局显示“定级中”，仍显示当前段位分对应的境界，定级期间不使用缓冲。
- 新人从 1000（金丹初期）起步，所以定级期输一局就会显示筑基；“定级中”标记说明这是暂时结果。

## 活动结束后结算

沿用 `settledMatchFilter` / `activityConcluded`：活动到点结束、提前标记结束或取消后，其比赛才计入可见段位分与境界；找不到活动记录的旧比赛完赛即计。活动进行中，本场已完成的小局显示“另有 N 小局待活动结束后结算（暂计 ±X 分）”，暂计值 = 包含进行中活动的完整回放分数 − 已结算分数。

## 排行榜

- 季度 / 年度综合榜积分 = 该周期每个计分小局的段位分变化之和 + 群主手动积分调整；单打榜 = 单打小局的段位分变化之和，不含手动调整。按马德里开赛月份归属，同分依次比较计分小局胜率、局均净胜，仍相同并列；正式账号的启用球友入榜，代报名朋友不入榜，这些都不变。
- 榜单保持即时：录入比分后，进行中活动的小局立即按完整回放计入，并在行内标注“含进行中 ±X”；活动结束后与境界同时确认。选择即时是因为活动中大家习惯立刻看到榜单变化，而段位分、境界的“活动结束再升降”保护的是徽章不在场上来回跳。两者在活动结束后完全一致（同一次完整回放），一个周期的积分总和等于这段时间段位分的变化。
- 计分局数、胜负、胜率、净胜只统计计分小局；让分局、友谊赛只计入“实际比赛”局数。
- 各月赛季规则里的 `win` / `loss` / `cap` 不再参与积分：数据保持原样可读，管理设置不再显示这三项，排行榜说明里的“各月计分规则”明细已移除。目标分、领先分、封顶分（比分校验）和 K（隐藏实力分）仍然有效。历史周期按新规则从现有比赛记录重新计算（数据从 2026-10-04 开始）。

## 迁移

`enableEloRealms` 由 `lib/club-maintenance.ts` 在首次读取时运行一次：只写入 `settings.realmVersion = 'elo-v1'` 并追加 `enableEloRealms` 审计（含每位球友回算后的段位分、境界、计分小局数和旧的成长底分）。段位分本身每次读取时由比赛记录派生，所有人从 1000 起回算，不使用 `initialRating` 或 `cultivationBase`（该字段保留可读、不再使用）。已有版本标记时不再执行，重复加载不增加修订号。原先的 weekly-v2 维护步骤已删除。

## 隐藏实力分

`replayRating`（每场一次、K 取赛季 `rules.k`、只算 2 对 2）和 `settledRatings` 原样保留，继续用于自动分组、让分建议、`strengthTier` 和比赛卡片的“队伍参考实力”。它与段位分各自独立。

## 模拟验证（合成球会）

16 名虚构球友，真实水平 N(1000, 150)，每周一次、每人约 8 局，按隐藏 Elo 均衡分组（与网站排场一致），30 个随机种子，直接调用 `realm-rating.ts`：

| 方案 | 第 52 周 炼气/筑基/金丹/元婴/化神 | 第 104 周 | 全员平均漂移（52 / 104 周） | 与真实水平秩相关（104 周） |
| --- | --- | --- | --- | --- |
| 个人计算（已采用） | 0 / 42 / 57 / 1 / 0 % | 0 / 41 / 57 / 2 / 0 % | +0.65 / +0.69 | 0.52 |
| 个人计算，分组随机 | 8 / 39 / 43 / 11 / 0 % | 8 / 39 / 43 / 10 / 0 % | +0.35 / +0.35 | 0.88 |
| 队伍平均（对照） | 25 / 23 / 24 / 16 / 12 % | 29 / 21 / 20 / 13 / 17 % | +0.36 / +0.36 | 0.94 |

- 不通胀：每局双方合计平均 +0.004 分；104 周后全群平均与 1000 的差小于 1 分（加入 6 名中途加入的强弱新人也只有 +1.2 分），因此不需要额外的零和修正。
- 境界分布：按个人计算时，强者总被分组搭配较弱的搭档，队伍胜率约 50%，但个人预期胜率按自己的高分计算，所以长期被拉回对手平均分附近：p10/p90 只有约 950/1050，几乎没人进入元婴或化神，且排名与真实水平的相关性随时间下降。门槛按决定保持 900/1000/1100/1200（队伍平均方式下分布接近目标 20/30/25/15/10%）；如需拉开分布，可把 `realmPolicy.doubles` 改为 `'team'`（同步修改说明中的个人示例）。
