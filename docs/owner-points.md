# 群主手动加积分

入口：我的 → 群组管理 → 手动加积分。选择启用的球友、计入月份、1–1000 的整数积分，填写原因后保存。

仅持久化群主身份可执行 `grantPoints`，普通管理员与成员不可使用。服务器忽略客户端 actor、isOwner、id 等字段。此命令沿用 `/api/club` 的认证、来源与请求体校验、限流、必需版本检查、请求 ID 幂等和 D1 原子提交。

加分作为结构化、不可编辑的 `audits` 记录持久化（action 为 `grantPoints`，changes 为 playerId、period、points、reason）。同一条记录同时构成加分账本与操作审计，不需要新表或重写已有数据。月份采用 2000–2100 年范围；比赛规则重算不改动加分记录。

榜单总分 = 有效计分赛积分 + 指定月份手动加分。季度、年度榜累加其月份内的记录；不改比赛、出场数、胜率、修为或 Elo。详细排名展示加分数额。加分记录入口仅群主可见，已有管理员操作日志与导出权限保持原规则。

验证：`tests/point-grants.test.ts` 覆盖权限、输入校验、周期汇总、修为隔离和投影；`tests/point-grants-api.mjs` 使用内存 SQLite 与真实 API/store 验证持久化、重复请求、并发版本冲突和回滚，不接触生产资料。
