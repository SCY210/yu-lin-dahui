# 球友电话号码

分摊场费时如果没有统一收款人，道友之间按「转账结算」各转各的，需要知道对方的电话号码（用来转账或 Bizum）。以前这些号码要靠收款人逐一转告；现在每位道友在自己的档案里留电话，转账时直接看到对方的号码。

## 填写

- 电话保存在 `Player.profile.phone`。格式与收款人电话相同：可以有开头的 +，只能包含数字、空格、括号和短横线，数字 5 到 20 位（`phoneProblem`，`lib/player-profile-options.ts`），前后空格会去掉。
- 自己编辑档案时，电话是必填项；没填时档案里标红「分摊转账需要，请填写」。旧版页面提交档案时不带电话，服务端保留原来的号码，不会清空。
- 单独的 `profilePhone` 命令只改电话：本人可以填自己的；宗主和副宗主可以替任何正式道友填写或修改。只能改性别的道友也能用它填电话。临时来宾没有档案，不能填。
- 和性别一样，没填电话的道友每次打开网站都会弹窗提醒（`app/phone-prompt.tsx`）。「即刻补录」打开只有电话一项的表单，「容后再议」到下次打开网站前不再提醒。性别弹窗先出现，电话弹窗排在它后面；通知提醒等这两个都关掉后再出现。

## 谁能看到

电话号码属于个人信息，不放进所有人都能看到的档案里。俱乐部视图（`lib/club-view.ts`）只把号码发给：

- 本人；
- 宗主和副宗主（看到所有人的号码）；
- 在有效的分摊版本里和自己有转账往来的人：自己要转给谁、谁要转给自己，以及有收款人时的收款人（`phonePeers`）。被撤回的分摊版本不算。

档案页只在本人、宗主和副宗主面前显示电话。

## 转账时显示

转账结算（`app/fee-transfers.tsx`）里，每笔和自己有关的转账都显示对方的电话和「复制」按钮；对方还没填时提示「还没填电话号码，可以在群里问一下」。其他人之间的转账不显示号码。有收款人但没有设置收款人电话时，提示里用收款人档案里的号码。

## 验证

- `tests/profile-phone.test.ts`：格式校验、本人与宗主副宗主的填写权限、来宾、旧表单保留号码，以及谁能在俱乐部视图里看到号码（含撤回的分摊）。
- `tests/phone-prompt-ui.mjs`：弹窗的出现、补录、稍后和被其他弹窗挡住。
- `tests/fee-transfers-ui.mjs`：转账行显示对方电话、未填提示、他人转账不显示，以及收款人号码。
