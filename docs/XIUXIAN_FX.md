# 水墨主题的修仙风交互

按群主要求，这一层交互和特效只在「水墨江湖」主题下生效，「清雅原版」主题保持原样；下面单独注明的布局修正和大屏适配除外。样式集中在 `app/xiuxian-fx.css`，整个文件包在 `html.wuxia-theme` 里；太极图标在 `app/taiji.tsx`。

这份样式和点按灵气（`app/spirit-touch.tsx`）从 `app/visual-theme.tsx` 的主题容器引入，不只挂在 `app/layout.tsx` 上。线上构建用的是私有版本的 layout（`docs/PRIVATE_RELEASES.md`），第一版只在公共 layout 里引入，结果线上没有这些特效。公共 layout 里原有的两行引入保留不动，避免私有仓库合并时冲突；点按灵气被挂了两份时只有先挂上的那份响应。

## 有哪些效果

纹饰图在 `public/xiuxian/`：祥云底纹、四个花角、远山剪影和一方「羽」字朱砂印，都是本仓库自己画的矢量图。

- **弹窗**：底色是带祥云暗纹的宣纸，四角是带云卷的金色花角，顶端一线灵光，底部一抹淡墨远山，右下角一方很淡的朱砂印；外圈双层金边。打开时一圈金光由外向内收拢。遮罩是墨色晕染并带模糊。纹饰画在弹窗背景上，内容滚动时不会跟着移动。
- **点按灵气**（`app/spirit-touch.tsx`）：手指或鼠标按下的位置绽开一圈金色灵纹、一圈朱砂虚线和几点金芒，约 0.7 秒消失。这一层不接收点击，同时最多保留几个节点。
- **全站底色**：宣纸上有缓缓流动的云气，页面底部是淡墨远山。
- **卡片**：右上角压一朵祥云暗纹，内圈一道金线；出现时自下浮现。活动卡左侧一道朱砂，悬停时托起并描金边。
- **按钮**：主按钮墨底金线，悬停或聚焦时一道流光掠过；按下任何按钮时外圈泛起朱砂与金色的光，松手后淡出。
- **站名**：每隔几秒一道金光掠过「羽林大会」几个字。
- **底栏**：顶边一线金光并带祥云暗纹；当前页的图标托起，背后一团灵光缓缓呼吸，下方亮起一道灵纹。
- **页签**：当前页签的文字和下缘泛光。
- **首页题头**：双层金边，几点灵气缓缓上升，标题缓缓泛光。
- **栏目标题**：标题前有一枚金色菱纹。
- **进度条**：境界进度、排行进度和道缘进度条里有一道光自左向右流过。
- **传音符（提示条）**：金边、光晕和祥云暗纹。
- **输入框**：聚焦时泛起一圈灵光。
- **太极**：延迟加载的区块等待时显示旋转的太极和「灵气汇聚中，正在加载…」；主屏幕应用里下拉刷新的图标换成太极，刷新时显示「灵气流转，正在刷新…」。原版主题仍是原来的文字和图标。
- 选中文字的底色和滚动条改成金色调。

## 补上原版样式的部件

逐页检查后，这些原来还是白底大圆角或淡紫色的部件，在水墨主题下换成了宣纸底、金边和小圆角：活动详情页的「场地接龙」概要、各场地卡片（含卡片顶部的渐变）、场地时间占用、人数标签、地图导航标签，宝阁的商品卡、储物戒和订单，各页的「功能说明」圆形按钮，排行榜的空领奖台，以及场馆地址和页脚链接的颜色。

## 约束

- 只做装饰，不改布局和功能，不发请求，不出声音。
- 动画只用 transform、opacity、box-shadow、文字阴影和背景位置；常驻的动画只有云气、站名金光、底栏灵光、题头和进度条这几处，都很慢。
- 系统开启「减少动态效果」时，所有动画关闭，静态纹饰保留。
- 文案遵守 `AGENTS.md` 的修仙口吻规定：修仙说法只做点缀，「正在加载」「正在刷新」这些实词保留。

## 手机上的操作优化

- 长表单（例如创建活动）在手机上有两三屏长。水墨主题下，「确认保存」按钮吸在弹窗底部，填到哪里都能直接提交；按钮不可用时改成不透明的灰色，不会透出下面的内容。
- 通知提醒弹窗在手机上超过一屏。水墨主题下，「开启」和「暂不祭出」两个按钮吸在弹窗底部，不用滚到最下面才能关闭。
- 活动详情页「场地接龙」下面的三个按钮在手机上挤在一行，「添加场地 / 时段」被挤成一列单字。现在它单独占一行（两个主题都生效）。
- 表单里的下拉框箭头以前会掉到文字下面一行，现在回到文字右侧（`app/native-form-select.css`）。这是布局错误的修正，两个主题都生效。

## 比赛实时比分大屏（iPad）

大屏（`app/live-scoreboard.tsx`）主要放在场边的 iPad 上，做了这些适配，两个主题都生效：

- 各场地的比分排在最前面，对阵图和小组积分表移到比分下面，打开就能看到比分。
- 字号、头像和名字随每张场地卡片的宽度缩放：一场比赛时占满整屏，两场时横屏左右并排、竖屏上下排列，三场及以上每行两张，四场比赛在 iPad 横屏和竖屏都能一屏显示。
- 打开大屏时请求屏幕常亮，iPad 不会自动变暗锁屏；切回页面时重新请求。浏览器不支持时不受影响。
- 「全屏」按钮兼容旧版 iPad Safari；在不支持全屏的环境（例如添加到主屏幕的应用）里不显示这个按钮。
- 留出刘海和圆角的安全区，按钮触控区域不小于 44 像素，大屏上不会误选中文字。

## 通知提醒弹窗

通知提醒弹窗（`app/notification-prompt.tsx`）重新排版，两个主题都生效：

- 开头一句话说明作用，并写明「此符可选，不开启也能正常使用网站」。
- 好处列成四条带图标的要点：新活动不错过；转正、上场即刻提醒；费用、评选、悬赏令；手机首次开启 +10 积分（单独用金色标出）。
- 积分规则收成一行「积分细则：开启 +10，关闭 −30（仅手机）」，点开才显示完整规则；加分和扣分的数字始终可见。
- 手机上整个弹窗一屏内显示完，按钮不用滚动就能点到。
