# 网站所有对局统一积分

所有网站记录的完整有效对局都自动计算排行榜积分：积分为 1000 + 段位分变化之和（见 [REALM_PROGRESSION.md](REALM_PROGRESSION.md)），净扣分显示为低于 1000。预排范围与开始时间只用于排场，不再控制积分开关；开赛或录分时即使旧客户端发送不计分标志，服务端仍统一计积分。取消、弃权、未完成对局保持原来的统计排除规则。

默认预排整个活动时段。取消自由赛、关闭积分和最后半小时不计分的界面选项。已应用让分的对局保存比分，但不计段位分、排行榜积分和隐藏实力分。

`enableAllRanked` 在已初始化群组中通过既有乐观 D1 事务一次性修复历史标记、回放实力并写审计；比分、球员、开赛与结束时间原样保留。重复加载不重复加分；后续生成、开赛和录分均强制采用统一规则。榜单继续按原有各月规则汇总。

验证包含历史 7 场记录中 4 场漏计分的真实 SQLite 迁移回归、幂等、回滚、时段外开赛、旧客户端标志、让分、自动胜负加减和权限。
