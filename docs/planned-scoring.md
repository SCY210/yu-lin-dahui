# 预排积分赛漏计分修复

开赛表单以前用 `max(活动开始时间, 当前时间)` 作为默认值。活动尚未到时间时，第二轮等后续轮次也被重置到活动开始，可能早于设定的积分赛开始；服务端按实际时间把比赛改成自由赛，保存比分后不计积分。

现在默认值使用 `max(活动开始时间, 本轮预排时间, 当前时间)`，沿用正确轮次。预排积分赛的时间越出计分区间时，服务器拒绝静默开赛；若活动管理者确实改为自由赛，须勾选明确选项。让分局仍不计积分或实力分。

比赛管理增加「修正计分方式」：仅活动创建者或管理员可调整已开赛对局的积分/实力分开关，填写原因并保留原始比分与时间。`matchScoring` 沿用真实事件权限、版本检查、请求幂等与事务，随后重算积分和 Elo。接龙成员仍可录分，但不能修改计分开关。

回归覆盖连续两轮完整开赛与录分、第二轮正常 +10/−3、越界开赛拒绝、明确自由赛、让分保护、修正后自动重算、原始数据保留和权限。真实 SQLite/API 回归验证修正落库与重复提交。
