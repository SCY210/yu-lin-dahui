# 锁组

双打活动里，组织者可以把两位球友锁成一组。锁组两人同一局上场时，总是站在同一边当搭档；同时每个人的上场次数与其他球友保持差不多（宗主要求，2026-11-14）。

## 谁能操作

- 宗主、副宗主和活动创建者（与其他排场管理相同），在活动结束前可以锁定或取消锁定。
- 所有球友都能在「搭档方式与投票」里看到当前的锁组。
- 只有正式接龙且未停用的球友可以锁组；每人同时只能在一个锁组里，要换搭档需先取消原来的锁组。
- 单打、练球活动和赛事不使用锁组。

## 排场规则

- **上场次数优先**：排场仍按公平轮转决定谁该上场。两人轮次相近（按原有「可互换」标准：欠的局数相同、等待相差不超过一轮）时一起上场、同队：轮到一人时，搭档顶替一位同样该上的球友，或把位置让给一位同样该上的球友、两人一起等下一次。
- **只轮到一人**：两人轮次差得多时（例如一人晚到、或人数让两人不可能每次都一起上），轮到的人先和别人打，另一人不在同一轮的其他场地上场；轮次对上后再一起上。模拟 20 多轮时，锁组两人与其他球友的上场次数相差不超过一局，大部分比赛仍是两人一起打。
- **同一局**：两人同在一局时一定是搭档，不会成为对手。
- **只来一人**：锁组暂不生效，这个人照常轮换。
- **固定搭档模式**：锁组两人直接组成一支固定队伍，其余球友照常配对。固定搭档已经分好、但还没开打时锁定新组，会按锁组重新分队；比赛开始后不能再改。取消锁组不会拆开已经分好的固定队伍。
- **擂台玩法**：擂主和挑战者按擂台规则产生，暂不使用锁组。
- 锁组优先于隐藏搭档概率；平衡修为、避免重复对手等其他规则在不拆开锁组的前提下照常生效。
- 手动换人、修改已发布对阵不受锁组限制，组织者仍可临时调整。

## 变更后

锁定或取消锁定后，尚未开打的预排积分赛轮次按新的锁组重排（组织者手动换过人的轮次保持不变）。实时排场从下一局开始生效。每次锁定和取消都会写入审计日志。

## 实现

- 数据：活动的 `lockedPairs`（`[球友ID, 球友ID][]`）。
- 规则：`lib/domain/locked-pairs.ts`（`lockedPartners`、`pickFour`、`keepsLocks`、`lockSplits`）。
- 命令：`lib/domain/locked-pair-commands.ts`（`pairLock`、`pairUnlock`），权限走 `authorizeEventAction`。
- 排场：`lib/domain/grouping.ts`（预排）、`lib/domain/live-play.ts`（实时排场）、`lib/domain/fixed-partners.ts`（固定搭档）。
- 界面：`app/event-points-plan.tsx` 的「锁组」区域。
- 测试：`tests/locked-pairs.test.ts`。
